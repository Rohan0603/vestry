# vestry

Name reservation. This crate contains no functional code.

**Vestry** is a durable local control plane for autonomous software engineering: one
developer states a goal, a deterministic orchestrator runs the full delivery lifecycle —
discovery, architecture, planning, decomposition, implementation, independent review,
verification with proofs, and closure — supervising external coding agents through an
adapter contract, and continues without manual follow-up until machine-checkable
acceptance criteria pass and the owner accepts.

Do not depend on this crate. Nothing here is stable and nothing here works.
