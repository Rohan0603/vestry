# VES-4 strict up-to-date demonstration (throwaway)

This file is part of the VES-4 branch-protection demonstration prepared under
T30. It is intentionally harmless prose and contains no requirement, decision
row, credential or configuration.

The pull request carrying it is labelled "DO NOT MERGE". Its purpose is to sit
behind `main` after an unrelated authorised merge lands, so that the strict
up-to-date gate can be observed in isolation on the next attempt.

If the demonstration is not run, this branch and pull request are deleted
without merging.
